# ECHO HUNT / エコー・ハント

透明な敵を視覚と足音で追う、オリジナルの一人称3Dブラウザゲーム。
**プレイヤー1人＋BOT7人。通信対戦はありません。**

公開先: https://hiroshi6844.github.io/test/echo-hunt/

## 遊び方

1. Safari、Chromeなどで公開ページを開く。
2. 「人間」「ヒドゥン」「ランダム」、開始装備を選び、「作戦開始」。
3. スマートフォン・タブレットでは横画面を推奨。イヤホンで足音の左右を聞く。
4. 人間はヒドゥン撃破で3点を獲得し、次のヒドゥンになる。ヒドゥンは人間撃破で1点。
5. 目標点または時間切れで個人順位を決定。同点は同率。

| 操作 | スマートフォン・タブレット | PC |
| --- | --- | --- |
| 移動 | 左スティック | WASD |
| 視点 | 右側をドラッグ | マウス。固定不可なら右ドラッグ |
| 攻撃 | 攻撃ボタン長押し | 左クリック長押し |
| ジャンプ | 跳躍ボタン | Space |
| リロード | 装填ボタン | R |
| 武器 | 武器ボタン | Q / 1・2・3 |
| 暗視 | ヒドゥンの暗視ボタン | N |
| 懐中電灯 | ライトボタン | F |
| 一時停止 | 右上のⅡ | Esc / 右上のⅡ |
| 順位 | 結果画面 | Tab長押し / 結果画面 |

移動・視点・攻撃の3指同時操作に対応。Pointer Lock・全画面表示は必須ではありません。
開始操作でWeb Audioを有効化。音声が開始できない場合もゲームは開始し、停止→再開で再試行できます。
タブ離脱・フォーカス喪失・回転では入力を解除。一時停止から手動で再開します。

## 実装内容

- 3種類の銃、距離減衰、連射間隔、リロード、独立した装填弾・予備弾、反動。
- 壁で止まる射線と近接攻撃。通常の人間への友軍射撃なし。
- 背景を屈折させるヒドゥンの輪郭、時間で弱まる透明度、攻撃時の露出、撃破で回復。
- 銃口発光、着弾、命中反応、被弾方向、刃の攻撃動作。
- 左右定位・距離・遮蔽物による減衰を伴う、オリジナルの合成効果音。
- 研究棟2棟の室内、20段の階段2組、屋上、広場、コンテナの路地、迂回路。
- 壁・床・天井・階段の衝突とジャンプ。
- 経路探索で移動するBOT。限定視界、音の曖昧な位置、時間切れになる目撃記憶。
- 人間BOTによる近くの仲間への目撃情報共有。ヒドゥンBOTの接近・奇襲・撤退。
- タイトル、設定、説明、HUD、停止、復活カウント、順位、結果、再プレイ、エラー画面。
- 画質3段階、感度、音量、BOT難易度3段階。目標点3〜100、時間2/5/10/15分、復活2/4/8秒。

## 初期バランス

単位はm・秒。数値はこのゲーム用の初期値で、原作の再現値ではありません。

| 項目 | 人間 | ヒドゥン |
| --- | ---: | ---: |
| 体力 | 100 | 180 |
| 移動速度 | 4.3 | 6.7 |
| ジャンプ初速 | 6.6 | 10.5 |
| 近接 | — | 射程2.3 / 55ダメージ / 間隔0.72 |
| 透明効果 | — | 32秒で低下 / 攻撃後1.1秒露出 / 撃破で回復 |

| 銃 | 装填 / 予備 | 基本ダメージ | 間隔 | リロード | 最大射程 / 減衰開始 |
| --- | --- | --- | --- | --- | --- |
| AR-24 | 24 / 144 | 22 | 0.12 | 1.9 | 50 / 26 |
| SG-6 | 6 / 48 | 15×8散弾 | 0.82 | 2.5 | 23 / 8 |
| P-12 | 12 / 96 | 31 | 0.27 | 1.35 | 38 / 17 |

最大射程で基礎威力の30%まで減衰します。死亡・役割交代で弾薬を補充。
復活・交代時は安全性を評価した地点に配置し、1.8秒の保護。自分が攻撃すると保護を解除。
ヒドゥン自滅は得点なし。生存人間から次を選び、全人間ダウン時は倒れている人間1人を即時にヒドゥンとして再配置します。

## 切り替え可能な追加ルール

| 要素 | 効果と扱い |
| --- | --- |
| 懐中電灯 | 前方16m・半角約30°。射線が通るヒドゥンの輪郭を強調。壁の裏は検知しない。人間BOTは自動使用。 |
| 補給箱 | 回復45、探知8秒、速度+30%を10秒、攻撃+35%を10秒。接触取得、22秒で再出現、予備弾も補充。取得得点なし。探知も壁越しに位置表示しない。効果は死亡・交代で消滅。 |
| 裏切り者 | 開始・ヒドゥン交代時に生存人間から1人。橙の装甲。人間だけを攻撃し撃破1点、ヒドゥンを攻撃・直接継承できない。人間による裏切り者撃破は1点。ヒドゥンによる裏切り者撃破も1点。死亡後は通常人間として復活。 |

## ファイルと開発

- `index.template.html`: 編集するHTML。`build.py` が更新識別子を付けた `index.html` を生成。
- `index.html` / `style.css` / `bundle.js`: そのまま静的配信するゲーム。
- `echo-hunt.html`: CSS・JSを内蔵する1ファイル版。外部読込ゼロ。
- `core.mjs`: ゲームルール、衝突、武器、BOT、経路探索。
- `renderer.mjs`: WebGL 1・GPU非対応時のCanvas 3D補助描画、軽量モデル、照明、背景屈折、手元武器。
- `audio.mjs`: Web Audioによる合成音。音声素材のダウンロード不要。
- `game.mjs`: UI、マルチタッチ、PC入力、固定ステップ、単一描画ループ。
- `tests/core.test.mjs`: Node.jsによるルール・衝突・階段・AIの検証。
- `qa.template.html` / `qa.html` / `tests/browser.qa.js`: ブラウザ統合検証。`?qa=1` の開発用インターフェースを使用。

外部ライブラリ・CDN・モデル・テクスチャ・音声ファイルへの依存はありません。
すべてのモデル・マップ・効果音はソースから生成します。GPUが利用できない場合は同じ立体モデルを透視投影する補助描画へ切り替えます。補助描画の最高解像度は1倍、画質「軽量」は0.65倍です。ビルドはPython標準ライブラリのみ。

```sh
python3 build.py
python3 -m http.server 8080
# http://localhost:8080 を開く

node --test tests/core.test.mjs
# http://localhost:8080/qa.html の実行ボタンでブラウザ検証
```

## GitHub Pagesで公開する場合

このリポジトリは既存のPages配信に `echo-hunt/` を追加しています。
別リポジトリでは、ゲームフォルダの内容をルートへ配置し、Settings → Pages → Deploy from a branch → main → /(root) → Save。
ルートに `.nojekyll` を置けばJekyll処理を省略できます。`index.html` は公開するフォルダ直下に必要です。
ブラウザでHTMLを開く場合はHTTP/HTTPS配信を推奨します。iOSのファイルプレビューはJavaScriptの実行環境ではありません。

公式手順: https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site
